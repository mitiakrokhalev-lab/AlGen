# Нотация условия: телескоп

Черновик расширенной схемы. Граф-схема AlGen остаётся ядром; здесь описано,
как записывается то, что в неё сейчас не влезает. Цель записи — чтобы каждая
задача из учебника выражалась одной записью без обходов кодом.

## Запись

```
∀ G : Grp            | fin-gen(G)          ← объявление вершины и посылки на неё
∀ N : Sub(G)         | normal(N)           ← тип зависит от уже объявленных вершин
∃ H : Sub(G)         | H ∩ N = 1           ← квантор у каждой вершины, по порядку
⊢ G ≅ N ⋊ H                                ← цель: формула, а не одно свойство
```

* Порядок строк — порядок кванторов. `∀` по умолчанию.
* Тип вершины — сорт словаря, возможно с аргументами: `Sub(G)`, `Mor(G, H)`,
  `Elt(G)`, `Mod(R)`, `Fam(Grp, I)`, `Ext(L/K)`, `ℕ`, `Prime`.
* Посылка после `|` — формула над уже объявленными вершинами.
* Построенные вершины пишутся термами прямо в формулах: `G/N`, `Z(G)`, `R[x]`,
  `cl A`, `X × Y`. Терм = вершина графа, как в AlGen.
* Цель — формула: атомы (свойства, отношения, равенства элементов, числа)
  под `∧ ∨ ¬ ⇒ ⇔` и, если нужно, под своими кванторами.
* `найти t` — цель-вычисление: ответ хранится термом или формулой от параметров.

## Метки расширений

Каждая задача в `задачи-проверка-схемы.md` помечена тем, что ей нужно сверх
нынешней схемы AlGen (v0 = выражается уже сейчас).

| Метка | Что добавить | Пример |
| --- | --- | --- |
| v0 | ничего | подгруппа свободной группы свободна |
| Q | чередование кванторов, ∃ в цели | всякая счётная группа вкладывается в 2-порождённую |
| P | параметры и числа как вершины (n : ℕ, p : Prime, \|G\|, ранг, степень) | группа порядка p² абелева |
| E | элементы и равенства с ними | x² = 1 для всех x ⇒ G абелева |
| D | семейства и диаграммы переменной длины, точные последовательности | лемма о змее, теорема Тихонова |
| F | цель-формула: ∨, ⇔, «найти», описание строения | Aut(Cₙ) ≅ (ℤ/n)ˣ |
| G | алгоритмические утверждения | проблема слов неразрешима |
| M | независимость от ZFC | проблема Уайтхеда |
| N | новые слова словаря (свойство, конструкция) без изменения схемы | Spec, V(I), рост группы |

N не меняет схему, только словарь, и отмечается для полноты.
