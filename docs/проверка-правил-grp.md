# Проверка правил раздела групп на конечных группах

Отчёт `python3 -m algen.check_rules` по таблице `data/finite/grp-small.jsonl`: все 1048 групп до порядка 100, все классы подгрупп, 1808 прямых произведений. Правила взяты из `data/grp.json` в развёрнутом виде (`tools/dump-rules.mjs`), вместе с полями `preserves`, `reflects`, `gives`.

**Нарушений: 0.** Подтверждено 161 правил из 302, не проверяется 139, не применилось ни разу 2.

Подтверждение здесь значит только «нет контрпримера среди конечных групп до порядка 100». Ошибки старой базы, найденные вручную, сидят в правилах и данных про бесконечные группы, и эта проверка их не видит.
