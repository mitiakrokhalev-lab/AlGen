# Проверенные выводы и отзыв источников одной строки

15.11.2026. Экспериментальный RowKnowledge поверх ValueLedger. Основной E.run
пока не переключён на очередь знаний. Область этого слоя — одна существующая
конкретная подстановка, один замороженный Theory и зарегистрированные выводы.

Источник задаётся неизменяемой парой имя/версия, явными примитивными фактами и
метаданными происхождения. Метаданные сами по себе ничего не доказывают.
Вызывающий код отвечает за математическое обоснование исходных фактов.
Первичная регистрация должна точно объяснить уже сохранённую строку; нельзя
назначить ей придуманное происхождение или незаметно стереть известные клетки.

Новый вывод требует совместности **всех** активных исходных фактов с Theory.
Затем проверяется невозможность противоположного значения. Сохраняется core
с точными типизированными атомами; сам core проверяется на совместность, а его
импликация — повторной SAT-проверкой. SAT-модель не записывается как группа
или факт. Неопределённый результат остаётся неопределённым.

Решатель создаётся заново из закреплённого снимка клауз. Контекст включает
полную типизированную схему атомов, точные клаузы и соответствие атомов вида
переменным SAT. Он не заимствует _derive hints или изменяемый решатель.
Смена владельца/буферов отвергается, содержимое проверяется хэшем на границах
операции и при создании решателя. Один объект сеанса обслуживает операции
последовательно; вложенная операция запрещена.

Прямые факты отделены от выводов. Проверка нового вывода использует только
прямые активные факты: прежние выводы не могут обосновать себя через цикл.
Для каждого литерала core сохраняются действующие версии поставщиков.
Альтернативные поставщики и разные зарегистрированные core не теряются.
Отзыв версии отключает зависимые зарегистрированные доказательства; другая
действующая опора может сохранить вывод. Возврат версии повторно проверяет
доказательство перед восстановлением значения. Старая история сохраняется.

Источники, применимость доказательств, полная проекция строки, классификации
всех зависимых сохранённых условий и подтверждение события меняются одной
транзакцией. Повтор подтверждённого knowledge-события идемпотентен; коллизия
с историческим публичным ledger-событием отвергается. Публичное обновление
зарегистрированной строки в обход этого слоя запрещено. Изменение опор при
неизменных битах всё равно создаёт новую ревизию.

## Что ещё не готово

Это замыкание **зарегистрированных** доказательств. Слой не вычисляет весь
backbone строки, не восстанавливает математический граф происхождения старых
Library-значений и не распространяет отзыв по всем строкам/конструкциям.
Условия сохраняют proof_pending; актуальные поддержки, надёжная входящая
очередь, архивные свёртки и полная граница кандидатов требуют отдельной работы.
Долг enumerate не закрывается. Все девять gates полного запуска открыты.

Ограничения: не более 512 активных пакетов источников и 4096 зарегистрированных
доказательств на строку. Бюджет SQLite относится к основному файлу, не к сумме
main/journal/TEMP/RSS. Дополнительный свежий SAT-решатель расходует память;
ресурсы и выигрыш измеряются отдельно. Private-поля и helpers — доверенная
внутренняя часть программы, не песочница для произвольного Python-кода.

## Контроль механики

Ниже протокол запланированного контроля. Успешного реального результата пока нет.

Контроль использует все сохранённые коды небольшой реальной схемы. Для одного
диагностического значения скрывается уже известная клетка; из исходного пакета
исключается вся её SAT-переменная. Остальные известные клетки — явно принятый
замороженный пакет предположений. Их первичное математическое происхождение
этим экспериментом не аудируется; новой математической находки здесь нет.
Диагностический поиск ограничен 32 попытками и уникальной переменной вида;
это ограничение выбора контрольной клетки, а не класса генератора.

Проверяются вывод скрытого значения, отзыв зарегистрированного пакета,
закрытие решателя, повторное открытие SQLite с новым решателем и восстановление.
Ожидаемые проекции берутся из внешнего исходного снимка; заново классифицируются
все сохранённые коды, проверяются их порядок, поддержки и подстановки.
Примитивные факты строки не дополняются form.fixed. Сырые SQLite и полный report
не выгружаются; сохраняются агрегаты, одно контрольное доказательство и хэши.
Результат этого контроля не является полным отчётом E.run или доказательством
суточного бюджета всего класса.
