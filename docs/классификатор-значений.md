Для запрета «посылки, фиксированный фон, отрицание цели»:

| Вид | Что известно по текущей таблице |
|---|---|
| A | Есть строка без ложных литералов, с одним неизвестным примитивным значением |
| B | Строки A нет; есть совместимая строка с двумя или более неизвестными |
| C | Каждую строку исключает известный ложный литерал запрета |
| R | Весь запрет известен истинным в некоторой строке: имеется опровержение |

R имеет приоритет над A/B: если опровержение уже есть, недостающие значения
других строк не делают условие ожидающим данных. События отдельных значений
у R могут сохраняться для диагностики; разреженные частоты включают только A.

Это характеристика данных, а не вердикт теории. Пустая библиотека даёт C,
не доказательство. Нужное значение кандидата A даёт контрпример;
противоположное исключает эту строку, а условие может остаться открытым.

Положительная пара раскрывается в знаковые примитивы; дубликаты, включая
fixed, считаются один раз. «¬P(H) и ¬P(K)» даёт две отрицательные составляющие.
Отрицание конъюнкции и несовместимый запрет явно отвергаются; эти входы
не возникают у допустимых минимальных условий действующего генератора.

Все события хранят (row,column), включая знак требуемого значения.
Для A считаются точные разреженные частоты; эвристическое value_name не
используется как идентификатор. Снимок битовой проекции свежий и неизменяемый:
Form._bits кэшируется по идентичности матрицы и мог бы устареть после правки
на месте. Исходные условия, поддержки и матрица не меняются.

SHA здесь описывает **числовую проекцию**, не заменяет архивный контекст.
При интеграции нужны отдельные привязки строк к подстановкам, столбцов к
атомам, версии таблицы и языка. Сливать схемы только по этому SHA нельзя.

Итератор: до4096условий и262144событий на блок. Переполненный блок делится
пополам; непоместившееся одиночное условие оставляет явную ошибку/долг.
Усечённого «полного» результата нет. Память самой проекции и всего архива
требует отдельного бюджета. Native-владение передаётся через слот вызывающей
стороны: finally установлен до вызова, память освобождается и при прерывании
на границе возврата. Это проверено регрессией и независимым sys.settrace.
