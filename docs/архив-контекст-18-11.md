# Контекст обновления архива: исправление 18.11.2026

[Draft PR23](https://github.com/mitiakrokhalev-lab/AlGen/pull/23) исправляет
маршрутизацию tools.live_values. Для одинакового имени схемы S существующий
контекст раньше выбирался первым по имени, даже если у новой выгрузки другие
Theory/library. На синтетическом воспроизведении пакет новой выгрузки мог
опровергать вопрос старого контекста. Это ошибка программы, не новый
математический red flag или группа-контрпример.

## Результат

Контекст считается по той же полной v1-идентичности base/class/theory/library/
declaration/fixed/variables, что в LiveArchive. Выделена чистая функция
context_identity; формат БД и допустимые JSON-идентификаторы v1 сохранены.
Уже импортированная схема переиспользуется только при совпадении полного
заголовка и всех записей в прежнем порядке. Служебный complete не позволяет
пропустить обещанные строки: проверяются целочисленные report_count и
unconditional_count, полный поток и EOF/gzip. Ошибка нового импорта откатывает
его транзакцию. Другой поток того же контекста не затирает историю.

Без выгрузки единственный контекст выбирается автоматически; несколько
требуют --контекст. Явный ID, противоречащий заголовку, отвергается до пакетов.
CLI передаёт в переразметку after.context, а не первый контекст БД.
Это guard контроллера live_values, не изменение всех импортных API LiveArchive.

Пример выбора: `python -B -m tools.live_values archive.db --контекст ID --значения packets.json`.
Для выбора контекста по заголовку передайте исходную полную выгрузку через --выгрузка.
Изменённые generation/данные отчёта при том же ID требуют явного разбора версии;
ошибка оставляет исходные записи, вместо подмены уже импортированной схемы.

## Что остаётся

Прямое сравнение Git blobs показывает: data/new/grp.json, logic.py, library.py
и finite.py различаются у кода пилотов e07ddc16 и исходного коммита сборки 06
daf2b93e; версии этих четырёх файлов в daf2b93e совпадают с текущим 0a723767. Нельзя без проверки контекста объявлять
этот переход только добавлением данных. Здесь факты 06 не применялись,
реального контроля 06→архив нет. Следующий шаг — версия формата строк с
декомпозицией Theory/языка/поколения и проверкой совместимости с архивом.

При новых данных Library fingerprint меняется ожидаемо: требуется явная связь
новых значений с прежними объектами и проверка неизменной семантики атомов и
конструкций. Изменение Theory или языка требует нового контекста и проверки
его покрытия; изменение класса учитывается отдельно.

запись переразметки не исправлялись этим PR и требуют отдельного аудита.
