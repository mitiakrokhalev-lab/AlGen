# SAT-предпочтения текущей схемы

7.11.2026. Реализация в PR14 поверх233f1c6/PR13. Измерения на6c3d0c8;
последующий compatibility guard6e633789 не меняет путь реальных форм.
Одна законченная оптимизация: при смене фаз Bank передаёт Glucose4 знаковые
предпочтения из прежних случайных векторов только для положительных cached ID
атомов текущей схемы. Раньше передавались случайные
предпочтения для всех примерно1,25млнпеременных каркаса. Теория, assumptions,
библиотека, числовой перебор, k≤3/s≤2 и guard сжатия не меняются.
Это эвристика поиска SAT, не фильтр кандидатов или переменных языка.

## От профиля к изменению

Диагностический префикс G-10-13: после минимизации обработаны ровно12000
вызовов cdecide, не12000готовых строк. Под cProfile участок занял188,179с;
166,921с ушло в native solve. Global:516вызовов/166,885с; Local:
550вызовов/0,050с. Bitset witness банка —0,501с, поэтому его отдельная
оптимизация этот начальный участок существенно не ускорила бы.

Уменьшать число предположений, принимать SAT локальной теории за SAT полной
или считать модель SAT группой-контрпримером нельзя. Вместо этого изменён
только список предпочтительных фаз. Cached ID читаются из T._lc, новые
переменные не создаются. Вне схемы и при отключённом режиме — старый путь.
Все четыре полных случайных вектора пока хранятся как прежде.

Table._one сохраняет token прежнего scope до регистрации. Даже прерывание
после записи нового scope восстанавливает внешний scope. Alarm отключается
перед cleanup. Независимый reviewer нашёл первоначальное окно прерывания;
оно исправлено и закрыто регрессионным тестом.
