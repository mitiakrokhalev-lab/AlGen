# Снимки диагностических harness

Файлы backend-<sha>.py — точные копии source на старте внешних проб,
ссылка каждой пробы на свой снимок и полный SHA есть в ../metrics-phase-scope.json.
verdict-prefix.py — сохранённый harness двух префиксов12000cdecide.
Это архив эксперимента, не новые production entry points.

Исходный checkout старых backend-проб —233f1c6, до изменения fast.py.
Проект и venv в эксперименте находились в /workspace/work/algen-dev и
/workspace/work/algen-venv. Пути жёстко заданы в сохранённых исходниках;
при другом расположении их нужно адаптировать и записать новый source SHA.
Для production измерения используется штатный tools/profile_memory.py.
Все тяжёлые запуски ограничены родительским watchdog; намеренная остановка
префикса не считается завершённой схемой.

Готовые исходные таблицы/Library/skel — тот же проверенный набор stress-02,
source_run42173383257, native fingerprint73a2a35d2480ac9c:G::s2:быстро.
Нужны именно эти inputs, кэш вердиктов не подгружать. Новый backend/префикс
не позволяет автоматически объявить исходный кэш другим или тёплым.

Полные raw и профили сохранены в рабочем каталоге; контрольные суммы и
проверки опубликованы в метриках. Автоматическая проверка отклонила загрузку
полного raw в публичный GitHub как потенциально непубличного артефакта;
он оставлен локально. В этом каталоге опубликованы только исходники harness.
