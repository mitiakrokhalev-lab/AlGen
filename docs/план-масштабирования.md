## Три показателя успеха

Время считаем отдельно: холодная сборка таблиц; полный первый перебор;
повторный перебор с кэшем; быстрое обновление примера; окончательное
восстановление минимальности и базиса после обновления. Записываем wall,
CPU дерева процессов, цену всех ошибок/повторов и стоимость диска.
Заявленный коэффициент проверяется на одинаковом полностью завершённом наборе и ресурсах.
Пилот с 50 проваленными/отсутствующими схемами таким эталоном ещё не является.

Для выдачи нужны два знаменателя: `Qraw/Qbasis` и `Qkept_old/Qbasis`.
На нынешнем успешном подмножестве ×1000 от 1 247 289 неизвестных № означает ≤1 247
вопросов, ×10000 — ≤124. ×1000 от уже сжатых 7 872 означает ≤7 вопросов;
это другая, гораздо более сильная цель. Все свёрнутые формулы остаются в
архиве с проверенными источниками. Компактная печать сама по себе не решает
математических вопросов. Универсальная задача-схема считается одной единицей
ручной работы только при проверяемом охвате её экземпляров.

Память: 0 OOM, 0 молча потерянных схем; запланировано=успех+явные незавершения.
Измеряем пик каждого процесса и всего дерева/cgroup, RSS по этапам, размер
живых условий, кэшей, report, число SAT-переменных/клауз, объём диска.
Целевой рабочий бюджет — не более 80% фактического лимита машины/cgroup
(порог предварительный). Если задача не помещается, делим работу или
выгружаем блоки на диск; не отбрасываем математические условия.

неиспользованным резервом. Новые математические данные для Aut/Inn/Φ/факторов
