## Исправление противоречивого фона сжатия

`py/algen/compress.py` побайтно совпадает с c449739, включая VERSION2 и
проверку совместности фона перед включением нового вопроса. Несовместимый
вопрос остаётся открытым и не становится основанием для произвольных свёрток.
В межсхемном `compress_base.py` этот guard тоже сохранён; проверки дополнены
требованием установленной совместности и явного UNSAT для доказательства.

Адресно выполнены существующие тесты:

- `TestCompress.test_opposite_questions_do_not_fold_everything`;
- `TestAcross.test_fold_across_schemes`;
- `TestAcross.test_full_verification_does_not_accept_solver_unknown`.

Итог:3теста за0,070с, OK. Независимый агент подтвердил ancestry, равенство
compress.py и повторил первые два теста:2за0,007с, OK, без пропусков.
Это проверка сохранения конкретного исправления. Полный текущий код уже
прошёл CI146; математическая корректность всего проекта этим не объявляется.
