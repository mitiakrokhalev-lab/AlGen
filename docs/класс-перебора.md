# Класс перебора и его инварианты

Это первое, что читает каждая новая сессия перед правкой генератора (py/algen/table.py, enumerate.py, logic.py). Здесь записано, что генератор обязан перебирать и что проверяет каждое обязательство. Сужать класс может только Дима.

## Класс

k ⩽ 3, s ⩽ 2 с тремя поправками (решения Димы 3.11). Определения и покрытие архива — в status.md, раздел «Класс перебора».

- **База** — объявление с ⩽ 3 главными переменными (`BASES`).
- **Вселенная базы** — все термы из ⩽ 2 конструкций (`size_universe`, ALGEN_SIZE=2) и все термы карточек архива из ⩽ 2 конструкций.
- **Схема** — замыкание набора термов, у которых вместе ⩽ 2 конструкций. Константы входят в каждую схему.
- **Атомы схемы** — все свойства словаря, подходящие сорту, у каждого терма, и все отношения словаря у каждой подходящей пары термов схемы.
- **Перебор** — все минимальные импликации из ⩽ 3 посылок, которые касаются каждого верхнего терма схемы.

## Инварианты и чем они проверяются

| инвариант | проверка |
|---|---|
| Каждая конструкция словаря — во вселенной (`CONS`, `SIZE_EXTRA`) или в `EXCLUDED_OPS` с причиной | `tests/test_class.py::test_every_construction_listed` |
| Каждая конструкция вселенной реально строится хотя бы у одной базы | `test_constructions_reach_universe` |
| У каждого терма — все подходящие свойства словаря (`FULL_PROPS`), `SKIP` пуст | `test_full_props` |
| Отношения (=, ⩽, сопряжённость, перестановочность, ≅, вложение) — у всех пар, а не только с переменной | `test_relations_all_pairs` |
| Ни один workflow не пропускает свойства флагом «--без» | `test_no_silent_skips_in_workflows` |
| Каждая карточка архива из класса перебирается | сверка (scratchpad audit.py; перенести в CI — задача A8) |

Тесты идут в CI на каждый пуш (`.github/workflows/tests.yml`).

## Что не перебирается и почему

Это реестр. Новая строка сюда добавляется только с решением Димы.

| что | почему | где в коде |
|---|---|---|
| whole-sub, trivial-sub, terminal | утверждение с ними равносильно утверждению без них | `EXCLUDED_OPS` |
| свидетели (hnn-hull, higman-hull, free-cover, free-cover-map) и choose-* | выражают «существует», не функции | `EXCLUDED_OPS`, `WITNESS` |
| free, pi1, units, meet-fam, join-fam | у баз нет переменных нужного сорта | `EXCLUDED_OPS` |
| симметричные повторы (A × B и B × A, eq(F, E) и eq(E, F)) | равносильны | `SYMMETRIC`, `SYMMETRIC_SUB` |
| вырожденные аргументы (x − x, НОД(x, x), уравнитель F с F) | вырождены | `DEGENERATE_EQ` |

## Ослабления вывода

Ослабления вывода не теряют утверждений класса и не дают ложных фактов. Они только добавляют вопросы.

| что | эффект |
|---|---|
| правила заземляются только на парах термов одной схемы (`logic.PAIR_FILTER`) | теряются выводы через термы чужих схем |
| ALGEN_FAST=1: значения таблицы только распространением | ≈ 9 % значений неизвестны |

## Ускорения, которые не меняют результата

Каждое такое ускорение проверяется сравнением со старым путём: результат должен совпасть бит в бит. Иначе это не ускорение, а сужение.

| что | почему результат тот же | проверка |
|---|---|---|
| заземление: роли правила берутся из построенных термов (связи-образцы, вложенные образцы, аргументы образцов) | подстановка без терма-образца всё равно отбрасывается | канон теории (атомы и клаузы) совпадает со старым кодом: Fam ✓; G, GE — сверка |
| перебор: набор посылок, где новый литерал верен во всех строках остальных, не продолжается (`PRUNE_FREE`) | все его неопровергнутые условия неминимальны; такие наборы вверх замкнуты | `tests/test_enumerate.py::test_free_set_pruning_keeps_output` (случайные таблицы, ловит мутации) |

## Сжатие выдачи: правила

Сжатие — отдельный слой после перебора (`py/algen/compress.py`, флаг ALGEN_COMPRESS). Перебор и его вердикты сжатие не меняет: ни одна строка не удаляется, прежние поля строки не меняются, добавляются только «№», «свёрнута», «следует из», «сжатие». Граница: всё до списка минимальных импликаций с вердиктами — тред ускорения; после — тред сжатия. Формат строки report меняется только с полем версии и по согласованию.

| инвариант | проверка |
|---|---|
| Сначала порядок по интересности (`interest_key`), потом жадный базис; строка сворачивается только через строки, стоящие раньше и оставленные (граф ацикличен) | `test_compress::test_order_matters_and_nothing_removed`, `verify` («источник стоит не раньше») |
| Ни одна строка не удаляется, прежние поля не меняются | `test_order_matters_and_nothing_removed` |
| Вопросы — гипотезы: свёрнутая строка хранит «следует из №…»; при опровержении источника она возвращается (транзитивно), повторное сжатие идёт без опровергнутых | `test_reopen_transitive_and_refuted_excluded` |
| Фон для вопроса — только теория (клаузы T) и гипотезы базы (`fixed_lits`) плюс оставленные вопросы под селекторами; значения таблицы, импликации «верные на таблице» и факты в фон не входят | код `compress` (решатель `T.solver()`, без матрицы формы); `test_facts_never_background_for_questions_and_vice_versa` |
| Факты доказаны теорией, их базис строится без теории — только из оставленных фактов | `test_facts_basis_without_theory` |
| Решатель не ответил (бюджет `CONF_BUDGET`, ошибка) ⇒ «не следует», строка остаётся | `test_solver_no_answer_keeps_row` |
| Вывод — полный SAT, не распространение: «не вывелось распространением» не используется как «не следует» | код `compress` (`solve_limited`) |
| Вопрос, который следует из одной теории, не сворачивается, а помечается «ОШИБКА сжатия» (значит, неверен вердикт) | `test_question_from_theory_alone_is_flagged_not_folded` |
| Каждая свёрнутая строка следует из своих источников — проверка новым решателем | `verify`; `test_random_soundness` (200 случайных теорий), `test_verify_catches_tampering`; на настоящей выдаче — `verify` на выборке |
| Экземпляр φ(t) по φ(G) сворачивается (не удаляется) только если: сорт t — группа; гипотезы базы (`fixed_lits`), класс ALGEN_CLASS и условия существования t (`requires`) выводятся теорией для t; R0 = φ(G) не опровергнут ни одной строкой библиотеки этого класса. Только вопросы; ссылка «экземпляр: R0» | `compress.instances`; `TestInstances`, `TestInstancesGeneric`; `verify` пересчитывает экземпляры заново |
| `enumerate.generic_filter` удаляет условия об одном терме без проверки класса и без ссылки — при ALGEN_CLASS это дыра (R0 о бесконечных группах нигде не спрашивается) | согласуется с тредом ускорения: под ALGEN_COMPRESS заменить на `compress.instances` |
| Регрессия до/после: ни одна строка не потеряна, ни одно прежнее поле (вердикт) не изменено, цепочка «следует из» кончается на оставленных — поэтому карточка архива в выдаче не теряется и не становится опровергнутой (свёрнутая считается найденной) | `compress.regress`; `TestRegress`; на настоящей выдаче — `regress` + `verify` на выборке в каждом замерном прогоне |

## Правила правки

1. Любой новый фильтр по термам, свойствам или отношениям — это сужение класса. Его решает Дима, и он записывается в реестр выше и в код рядом с `EXCLUDED_OPS`.
2. При смене класса каждое сужение из старого кода нужно проверить заново. Дыры 3.11 возникли именно так: сужения под класс d ⩽ 2 остались, когда класс стал s ⩽ 2.
3. Перед запуском на GitHub — `cd py && python3 -m unittest discover -s tests`.
