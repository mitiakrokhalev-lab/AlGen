# Переделка AlGen

## Цель

Реестр общей алгебры и топологии из трёх частей:

1. **Словарь**: сорта, конструкции, свойства, отношения с точными определениями.
2. **Базовые правила**, из которых выводится учебная теория: подгруппа свободной
   свободна, компактность сохраняется непрерывными образами и т. д.
3. **Остаток**: факты, которые не закрыл бы идеальный генератор. Факт
   нетривиален, если его нельзя отбросить, потому что условие ослабляется, есть
   понятный контрпример, условие распадается или факт коротко выводится из
   правил. Над нетривиальным фактом человеку надо подумать хотя бы три минуты.

Всё, что выводится из правил и примеров, отдельно не хранится.

## Главный принцип

Статус факта меняют только проверяемые источники: вычисление (GAP),
курируемая база (π-Base, DaRT), формальное доказательство (Lean) или человек.
Нейросеть предлагает правила, объекты и доказательства, но не подтверждает их.
Всё, что она добавила, имеет статус «не проверено», пока не проверено
источником.

Старая версия этого принципа не держала. Правила и свойства бесконечных
объектов писались рукой и сверялись друг с другом, поэтому ошибки в них
подтверждали друг друга.

## Устройство

```
словарь (data/*.json, переносится из старой версии)
   │
   ├── объекты с источником у каждого значения
   │     конечные группы ........ GAP SmallGroups      data/finite/
   │     топология .............. π-Base целиком
   │     кольца ................. DaRT + GAP/Sage для конечных
   │     бесконечные группы ..... своя база по образцу π-Base, со ссылками
   │
   ├── факты (телескоп, docs/нотация.md) со статусом и обоснованием
   │
   └── генератор-фильтр (Python)
         1. перечисление условий, канонизация, минимальность
         2. вывод: SAT/SMT по доказанным фактам, с разбором случаев
         3. поиск контрпримера: таблица объектов + синтез (×, ⋊, ≀, ∗)
         4. попытка доказательства: Prover9 / Lean
         5. остаток человеку; решённое возвращается в базу фактом
```

Вычисления идут вне браузера. Страница только читает готовую выгрузку и служит
для просмотра и ручной разметки.

## Мерило

Число пробелов и кандидатов мерилом не служит: оно зависит от состава
библиотеки. Мерило — эталон `data/etalon/эталон.jsonl`, факты с известным
ответом:

* всё с ожиданием «отсеять» генератор обязан закрыть, и закрыть верно;
* всё с ожиданием «выдать» (известные открытые задачи) обязано дойти до
  остатка.

Каждый разобранный человеком факт из выдачи пополняет эталон.

## Этапы

Каждый этап — отдельный пулл-реквест, и старый код работает, пока его часть не
заменена.

1. **Фундамент.** Таблица конечных групп из GAP, проверка всех правил базы на
   ней, эталон, этот план. *(этот PR)*
2. **Шире проверка.** Гомоморфизмы, прямые произведения и элементы в таблице
   конечных групп, чтобы проверялись и остальные правила. Импорт π-Base
   целиком. Переаудит `data/infinite.json` по литературе.
3. **Вывод на SAT.** Правила заземляются на граф условия и решаются
   SAT-решателем. Это даёт разбор случаев и дизъюнкции, которых нет у Хорна.
4. **Новый перебор.** Расширения нотации P и F (параметры, цель-формула),
   минимальность условия, корзины по причинам из определения нетривиальности.
5. **Синтез контрпримеров** конструкциями под конкретные посылки.
6. **Кванторы и элементы** (расширения Q и E), Prover9 / Mace4 для тождеств.
7. Кольца, модули, поля на новом движке; страница поверх выгрузки.
