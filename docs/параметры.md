# Условия с параметрами (расширение P)

`py/algen/params.py` разбирает и проверяет условия с числовыми параметрами:

```
∀ p, q : Prime | p < q; ∀ G : Grp | ord(G) = p q; ∀ H : Sub(G) | ord(H) = q
⊢ normal(H)
```

## Запись

* Сорта параметров: `Prime`, `ℕ` (с 1). Группы — `Grp`, подгруппы — `Sub(G)`.
* Числа: целые, переменные, `+ − · ^` (произведение можно писать подряд:
  `2p`, `p q`), `ord(G)`, `index(G, H)`, `gcd`, `lcm`, `phi`.
* Группы: переменные, семейства `C(n)`, `D(n)` (порядка 2n, самосовмещения
  n-угольника), `S(n)`, `A(n)`, `Dic(n)` (порядка 4n), произведение `×`,
  фактор `G/N`, центр `Z(G)`, коммутант `commutator(G)`.
* Формулы: свойства словаря, `prime/even/odd`, сравнения `= ≠ < ≤ > ≥`,
  делимость `|`, изоморфизм `≅`, связки `¬ ∧ ∨ ⇒ ⇔` (запятая — это ∧).

## Проверка

Параметры пробегают простые и натуральные числа до 100, группы — таблицу
GAP (порядки ⩽ 100 и досчитанные), подгруппы — классы сопряжённых
подгрупп. Номера SmallGroup для семейств лежат в
`data/finite/grp-families.json` (`py/algen/gap/families.g`). Если в группе
известен порядок из посылки `ord(G) = …`, перебираются только группы этого
порядка.

* Пример, где посылки верны, а цель ложна, опровергает условие. Это
  понятный контрпример: конкретная конечная группа.
* Если такого примера нет, условие **верно на всех примерах до границы**.
  Это проверка, а не доказательство, поэтому в архиве такая карточка
  попадает в корзину «проверено на примерах», а не «закрыто».

Подгруппы в таблице — представители классов сопряжённости. Поэтому
утверждение «подгруппа порядка q одна» записывается как «H = K и H
нормальна» для любых двух представителей H, K порядка q.

## Архив

Карточка с полем `"расширение": "P"` идёт через эту проверку. В задачнике
Дыбковой так записано 9 задач: 1.23, 2.26, 3.11, 5.3, 5.5, 5.6 (7), (8),
7.12 и контрольная «группа порядка p³ абелева?». Ложная опровергается
контрпримером D₄, остальные 8 верны на всех примерах.

## Чего нет

Вывода. Чтобы закрывать параметрические задачи, нужен числовой слой
в SAT-выводе: атомы о строении порядка (p-группа, p², pq, наименьший
простой делитель, взаимная простота) и правила Лагранжа, Коши, Силова,
формулы классов. Это следующий шаг. Задачи «найти» (число классов
сопряжённости Dₚ, |Aut(Cₙ)|) требуют ещё и вычисляемых функций от
группы — это расширение F.
