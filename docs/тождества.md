# Тождества в элементах (расширение E)

Задачи вида «если G′ ⩽ Z(G), то [ab, c] = [a, c][b, c] для всех a, b, c»
решает `py/algen/identities.py`.

## Как решается

Тождество u = v верно во всех группах многообразия тогда и только тогда,
когда оно верно в относительно свободной группе этого многообразия, ранг
которой равен числу переменных. Поэтому достаточно посчитать в одной группе.

* **Все группы.** Относительно свободная группа — свободная. Слово u⁻¹v
  свободно сокращается; тождество верно, если остаётся пустое слово.
* **Нильпотентные ступени ⩽ c.** Свободная нильпотентная группа F/γ_{c+1}F.
  Она вкладывается в единицы кольца ℤ⟨X₁, …, Xₙ⟩ по модулю мономов степени
  больше c: xᵢ ↦ 1 + Xᵢ, xᵢ⁻¹ ↦ 1 − Xᵢ + Xᵢ² − … По теореме Магнуса ядро
  этого отображения на свободной группе — ровно γ_{c+1}F. Тождество верно,
  если образ u⁻¹v равен 1. Абелевы группы — c = 1, «коммутант в центре» —
  c = 2.

Ответ точный в обе стороны. Если тождество неверно, контрпример — сама
относительно свободная группа, а ненулевой член образа его предъявляет.
Прочие посылки условия контрпример тоже должен выполнять. Безопасны те,
что верны в относительно свободной группе или в её конечных p-факторах:
нильпотентна, разрешима, ф. а., к. п., линейна, полициклична, хопфова,
конечна, периодична, без кручения. Конечность вместе с отсутствием
кручения уже не годится. С другими посылками генератор отвечает
«неизвестно».

## Запись

```
∀ a, b, c ∈ G:   [a b, c] = [a, c][b, c]
```

Произведение — подряд или через `*`; обратный — `⁻¹` или `^-1`; степень —
`^3` или `³`; сопряжение `a^b = b⁻¹ab`; коммутатор `[a, b] = a⁻¹b⁻¹ab`,
`[a, b, c] = [[a, b], c]`. Соглашение `xyx⁻¹y⁻¹` задаётся полем
`коммутатор` карточки.

```
cd py && python3 -m algen.identities "[a b, c] = [a, c][b, c]" --ступень 2
```

## Чего нет

Многообразия без такой явной модели: разрешимые ступени 2 (метабелевы),
периода n, их пересечения. Для метабелевых есть вложение Магнуса в
сплетение, для малых периодов — конечные свободные бёрнсайдовы группы,
для остальных — Prover9 / Mace4.
