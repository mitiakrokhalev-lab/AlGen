## Что ускорено

size_universe теперь заранее формирует pools по сортам входных слотов через
тот же Vocab.fits, который использует Graph.make. Это подпоследовательности
прежних pools; порядок допустимых tuples сохранён. Включено наследование
Sub→Obj. Quotient расширяет canonical-pool перед фильтром, а зависимые
ambient/dom/cod и определённость по-прежнему проверяет Graph.make.
Отвергаемые по сорту tuples не могли менять граф до проверки ссылок.

Независимый review подтвердил это по коду и проверил точное равенство

## Возобновление и цена всех попыток

`tools/build_scheme_manifest.py` запускает одного ребёнка на базу и хранит
immutable attempt-каталоги с логом, прогрессом, receipt и gzipJSONL.
Готовые файлы одного контекста проверяются и переиспользуются. При смене
source/data context нужен новый каталог, старый сохраняется. Повреждённый
файл не удаляется и не сохраняет статус complete. Неизвестное число — null.

Попытка регистрируется до Popen. Используются flock, pid/birth identity,
cleanup своего child при ошибке и Linux PDEATHSIG с проверкой startup race.
При прерывании незавершённая попытка имеет явный долг и неизвестную стоимость,
а не выдуманный ноль. RSS ребёнка опрашивается родителем каждые50мс; дополнительно
ребёнок имеет собственный wallalarm и отдельный RLIMIT_AS.

## Воспроизведение

```sh
cd py
python3 -B -m tools.build_scheme_manifest --out /tmp/algen-plan-new --seconds 30
# Тот же каталог: complete-файлы переиспользуются, недоделанное продолжается.
python3 -B -m tools.build_scheme_manifest --out /tmp/algen-plan-new \
  --bases GHK GMN GHK2 --seconds 120
```

Контроль старого пути: --legacy или ALGEN_TYPED_UNIVERSE=0 при обычном вызове
table. Бюджеты planner по умолчанию: childRSS1536MiB (опрос родителем), childAS3072MiB,
disk reserve40/32MiB. Это технические ограничения inventory, не admission
памяти для задач. Source fingerprint table.py сохранён, кэши не обходятся.

Теперь известен N для ресурсного расчёта: при20полностью занятыхCPU24ч дают
11,60CPU-секунды/схему до таблиц/архива/сжатия/ошибок. W_cpu, длинный хвост
и безопасная память задач ещё неизвестны;24ч не подтверждены. Manifestgate
частично закрыт: inventory_complete=true, mathematical coverage audit=false.
