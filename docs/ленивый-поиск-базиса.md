## Как сохраняется покрытие при обновлениях

Meta-SAT хранит структурную область кандидатов: обе полярности, k, req/fixed
и покрытие выбранными литералами. Кандидаты, временно закрытые библиотекой
или условным базисом B, остаются в этой области. Алгоритм не строит явный
список всей области; в худшем случае число извлечений может достигать полного
числа кандидатов. Полный перебор для проверки выполняется отдельным оракулом.

Один solver содержит исходную T и guarded-клаузы гипотез. Возможность
истинной цели проверяется при выключенных ВСЕХ гипотезах B; возможность
ложной цели — с текущим совместным B. При UNSAT сохраняются core,
assumptions, фаза проверки, вопрос, снимок B и точные зависимости.
В meta добавляется только подтверждённый запрет соответствующего набора
селекторов. Нельзя переносить admission-UNSAT на целое дерево усилений:
несовместимый с B вопрос остаётся отдельным явно сохранённым исключением.

Каждая библиотечная строка и каждый cut включаются своим guard. Новый
пример снимает только действительно опровергнутые вопросы; cut отключается,
если снята хотя бы одна гипотеза из его deps. Незатронутые B, исключения и
доказательства сохраняются. Отзыв/реактивация строки меняет её guard;
ранее скрытые кандидаты могут появиться снова. ID вопроса не назначается
другой формуле. Exact block активен лишь пока вопрос явно сохранён.

Первая мутация строки заранее инвалидирует отметку полноты и меняет revision.
Ошибка/прерывание не даёт новой отметки complete. Новые guard ID не повторно
используются после незавершённой записи; иначе осиротевшая условная клауза
могла бы включиться вместе с чужим доказательством. Эти окна закрыты
fault-injection тестами, одно из них найдено независимым reviewer.

Проверяются добавление, отзыв и реактивация строк в одном процессе. Контекст
языка/класса фиксирован; смена T и языка требует нового сеанса. Сериализуемый
receipt содержит историю доказательств, но восстановления solver из него,
интеграции с SQLite/worker, транзакций между процессами и обработки новых
теорем ещё нет. Длительная динамика/ограничение памяти истории не измерены.
