Контроль сборки 06 воспроизвёл прежний полный отчёт по хэшу. Проверена совместность всех 32 183 строк проекции (5 522 различных сигнатур) с прежней и пополненной ограниченной Theory. Противоречивых строк нет. Пакет доказал 2 из 3 прежних C-вопросов. Прямой вывод заполнил 2 858 ячеек. Новых опровержений среди прежних неизвестных от этих ячеек не появилось. Дочерний процесс занял 670,43 с wall и 658,91 с CPU при пике 10,94 ГиБ. [Контроль](https://github.com/mitiakrokhalev-lab/AlGen/actions/runs/44325839799).

Размер ветки подготовки правил ограничен. В проверку строк входят известные положительные и отрицательные литералы проекции; совместность проверяется по их конъюнкции. SAT использован для проверки теории. Опровержения считают по конкретным строкам из библиотеки, содержащим весь запрет.

На старом полном снимке пилота 18 пять доказанных значений отношения вложимости в Aut закрыли 151 прежний неизвестный ID, в том числе 35 из 625 оставленных. Все 35 перешли из A в опровергнутые. Для той же области хватает пары: отрицательное значение для C₂³ и положительное для любой одной из C₂⁴, C₂⁵, C₂⁶, C₂⁷. Четыре положительных значения дают одно и то же множество из 31 оставленного запрета, а отрицательное значение добавляет ещё 4. Это оценка покрытия прежних ID. Состав нового базиса не рассчитывался. [Исторический запуск](https://github.com/mitiakrokhalev-lab/AlGen/actions/runs/43986399971).

Для C₂³ группа Aut есть GL₃(F₂) порядка 168. Верхняя унитреугольная подгруппа имеет порядок 8 и некоммутативна, поэтому все подгруппы порядка 8 некоммутативны как силовские. Для размерностей 4–7 блочные матрицы с единичными диагональными блоками дают элементарную абелеву подгруппу ранга ⌊n/2⌋⌈n/2⌉ ≥ n. Привязка к ключам групп проверена отдельно по сохранённой Library. Это доказательства для ранее записанных GAP-объектов.

Давать агентам ограниченные партии с измерением новых закрытых ID. Для конечных групп брать конкретные недостающие значения или подстановки и вычислять их в GAP, когда расчёт практически выполним. Для общих правил и бесконечных групп нужны доказательство и независимое ревью. Перед внесением проверять, что значение всё ещё отсутствует на текущих входах, а правило согласуется с Library. A ранжировать по точному объединению опровержений. Для B считать целые наборы недостающих значений в одной строке. Измерять отдельно долги A/B, C, байты отчёта, время и память. В следующей партии сначала проверить на свежих таблицах значения для C₂³ и C₂⁴ из опыта с перекрытием.

Пакет находится в экспериментальном файле, действующая Theory и Library с ним ещё не построены. При принятии правил нужен новый контекст. Проверки считают доказательства и свидетелей для уже известных ID. Для оценки нового остатка и размера отчёта нужны минимальность и пересборка базиса после обновления.
