## Железные правила (Дима)

1. **Класс.** Все задачи абстрактной теории групп с ⩽ 2 построениями и
   ⩽ 3 посылками на свойство. Перебор полный в этих границах. Ни фильтр,
   ни отсев, ни сжатие не сужают класс. Отсев допустим только с проверяемой
   причиной покрытия, которая хранится.
2. **Цель.** Полный архив: генератор находит все вопросы и отбирает
   первично, остаток разбирается руками. Конечная цель — каждая задача
   выводится из вопросов библиотеки за секунды.
3. **Один полный перебор** за ⩽ сутки (при необходимости — аренда железа,
   до 1000 ₽/сутки, по согласованию). Память не должна ломаться ни на одной
   схеме.
4. **Динамическая связь библиотека ↔ архив.** Новое правило или пример
   быстро закрывает задачи архива и раскрывает зависимые, без повторного
   полного перебора.
5. **Красный флаг** (уточнение Димы 8.11): известная задача (из памяти,
   учебника, задачника, архива `data/archive/grp`), которую **нельзя
   синтаксически записать** так, чтобы генератор с ней работал: нет слова в
   словаре или любая запись выходит за ⩽ 2 построения / ⩽ 3 посылки /
   ⩽ 3 переменных базы. Записывается, но не выводится — не флаг, а вопрос.
   О флагах сообщать Диме; решение о расширении словаря/класса — за ним.
6. **Проверки.** Независимый агент-проверяющий на каждое изменение.
   Ускорение засчитывается, только если выдача совпала бит в бит.
   Оценки помечаются как оценки.
7. **GitHub.** Пилоты запускаю сам (разрешено 8.11); о каждом запуске
   сообщаю: что, ссылка, когда ждать. Ничего не удаляю и не сливаю в main.

и замораживаются на этапе 6. Каждое расширение увеличивает класс — его цена
считается переписью до запуска.

## Реестр красных флагов

Источники: архив `data/archive/grp` (541 карточка, корзина «красный флаг»
инструмента `algen.archive`), аудит выборки 7.11, проверка классических задач
8.11 (независимый агент ищет равносильную запись каждого кандидата).
Таблица заполняется по итогам этих проверок.

Проверка 8.11 (независимый агент, 18 классических задач; пробы и выводы —
`tools.audit_holdout`, черновики вне репозитория). «Нет слова» → дорожка «Язык»
(Я1/Я2/Я4); «вне s» → Я3 (длинные схемы, решение Димы).

| Задача | Почему не записывается | Куда |
|---|---|---|
| Тождества в элементах: (ab)² = a²b² ⇒ абелева; x ↦ x⁻¹, x ↦ x² — гомоморфизм ⇔ абелева; нечётный порядок ⇒ x ↦ x² биекция | нет умножения/степени элементов в схемах; элементный слой — только «свойства ⇒ тождество» | Я2 |
| ord(xy) = ord(yx) | нет произведения элементов (заменой y = x⁻¹z сводится к «сопряжённые одного порядка», но это и есть решение) | Я2 |
| Aut(C_n) ≅ (ℤ/n)ˣ | (ℤ/n)ˣ не строится в разделе групп | Я4 |
| HK — подгруппа ⇔ HK = KH | нет терма «множество HK» (есть permutes, prod-card) | Я4 |
| Длина Хирша, h(G) = 0 ⇔ конечна | нет слова | Я4 |
| Уравнение классов; число элементов порядка p ≡ −1 (mod p) (Putnam); теорема Фробениуса о числе решений xⁿ = 1 | нет сумм/подсчётов элементов | Я4 |
| Лемма Фиттинга | нет нильпотентного эндоморфизма, нет «нормального эндоморфизма» (без нормальности ложно: S₃) | Я4 |
| 2-я и 3-я теоремы об изоморфизме; Z(A×B) ≅ Z(A)×Z(B), (A×B)′ | вне s ⩽ 2 (s = 5–7) | Я3 |
| Аргумент Фраттини; [G : core H] делит n!; формула Шрайера; автоморфизм порядка 2 без неподвижных точек ⇒ абелева | вне s ⩽ 2 (s = 3–6) | Я3 |
| k(G), exp(G) как числа | были «нет слова»; закрываются Я1 (k(G) = |G| ⇔ абелева; exp = max ord) | Я1, в работе |

Архив `data/archive/grp`, прогон `algen.archive` 8.11 (после исправления
`params.Model`, падавшего на Sym(n)): 541 карточка — закрыто генератором 453,

классах = core (две задачи класса). Вероятность коммутирования — вычеркнута (Дима).
