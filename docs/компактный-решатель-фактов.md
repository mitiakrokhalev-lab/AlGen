# Компактная нумерация решателя фактов

14.11.2026, PR20. Library, Theory и класс задач прежние. Оптимизация меняет
только отдельный SAT-решатель фактов SF, который не содержит клауз Theory.
Решатель вопросов SQ, совместность фона и проверки зависимостей сохранены.

Прежде SF получал номера переменных из многомиллионной Theory, хотя в нём
встречались только атомы текущих фактов и fixed. Теперь эти атомы получают
компактные номера с сохранением порядка. Знаки в предположениях, клаузы,
fixed, селекторы и запросы уменьшения ядра переименованы согласованно.
Контрольный прежний режим — ALGEN_COMPACT_FACTS=0.

Это биекция переменных, сохраняющая выполнимость. Она сама по себе не
доказывает совпадение конкретного SAT-ядра при ограничении конфликтов:
нумерация может влиять на поиск. Поэтому сравниваются полные report, включая
зависимости, и сохраняется контрольный режим. Исправление идентификаторов V3
применено к обоим режимам; со старыми служебными полями V2 сравнение не ведётся.

Диагностический cProfile одной выборки 1024 условий показал 166,982 с внутри
compress, включая 111,447 с solve_limited. Последнее число объединяет SF/SQ/SB,
а вложенные cumulative-времена нельзя складывать. Базовая подготовка хэшей
клауз в этот профиль не входит. Метрики: metrics-value-profile-01.json.

## Измеренный полный отчёт одной малой схемы

G-14-217: sym(G), torsion(sym(G)), k=3, таблицы сборки 43434101930.
Обработаны все 1908 минимальных условий. Обе проверки используют одинаковый
код, входы, V3 ID и прочие параметры; запись архивного кэша и cProfile отключены в обоих.

Первая пара на разных hosted runners дала 154,231 → 111,661 с, но отличалось
время подготовки. Поэтому проведён контроль на одном runner: два свежих
процесса последовательно, compact первым, global вторым. Общая подготовка
native-компилятора 2,209726 с записана отдельно.

| Дочерний процесс | Global | Compact |
|---|---:|---:|
| Wall, с | 188,798 | 154,998 |
| CPU, с | 185,863936 | 151,641128 |
| Пик RSS, GiB | 11,266247 | 10,790108 |

Наблюдаемый выигрыш wall — 17,90273%, CPU — 18,41283%; память меньше на
0,476139 GiB. Это одна пара одной схемы с фиксированным порядком. Влияние
порядка и OS cache не устранено. Затраты будущего архива сюда не входят;
оценки суток для всего класса из этого измерения нет.

Во всех четырёх процессах runtime SHA полного report:
e583c58440eb06ebc90589d8228aebac0a2e2c1f26c40e691b87b9773f301751.
Текстовая выдача побайтно одинакова; содержательные поля сводок и граф
зависимостей совпали. Сырые 1908 строк отдельно не архивировались, поэтому
независимый rehash этих строк не заявляется: проверены код потокового хэша,
runtime receipts, сводки, все члены ZIP и удалённые логи.

Однородные счётчики: 1908 raw-строк = 1906 доказанных + 2 неизвестных;
оставлены 473 = 472 доказанные + 1 неизвестная, свёрнуты 1435. Render отдельно
содержит 990 классов. В нём 271 уникальный ID оставленного факта; это другой
знаменатель. Количество выдачи между global/compact не изменилось.

## Проверки и следующий участок

39 локальных тестов, включая одинаковый полный report при разреженных
глобальных номерах и отрицательном fixed, ограничение числа переменных SF,
освобождение двух решателей при прерывании подготовки. Дифференциально:
1085 совместных учебных теорий из 1200 seeds, 26984 условия, равные report dict;
115 несовместных теорий пропущены явно. Независимо — 32 краевых набора.
Первый полный CI закончился одним SIGALRM-error из 257 тестов за 3017,934 с.
После ремонта доставки сигнала и прерываемой обрезки keys/support повторный
CI43617302145 прошёл: **259 тестов за 2558,471 с, OK, без пропусков**,
код 3c862bb. Исходники и итог независимо проверены. Compact SF при этом
не менялся; прежний сбой и его стоимость сохранены в метриках.

Факты составляют почти весь этот малый отчёт; замер не представляет тяжёлые
схемы с преобладанием неизвестных. Следующий кандидат времени — массовая
проверка покрытых предположений по формальным моделям SAT-банка в числовом
виде, затем измерение на неизвестных схемах. Модель Theory может подтверждать
невыводимость из текущей Theory, но не служит группой-контрпримером Library.
Пропуск вызовов должен сохранять наблюдаемые ответы/зависимости и учитывать
версии банка, перезапись моделей и запись кэша; этот путь пока не реализован.

Переход к работе от знаний также требует журнала условий и точных наблюдений,
индекса зависимостей всех A/B/C/R и отдельной очереди отложенных доказательств.
Для будущих более сильных минимумов нужна полная явная или символическая
граница. Числовой классификатор и компактный SF её не заменяют.
Подробные первичные числа и независимые receipts — metrics-compact-fact-sat.json.
