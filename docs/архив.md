# Архив фактов

Архив — третья часть реестра (docs/ПЕРЕДЕЛКА.md): известные задачи с
ответом, обоснованием и местом, которое им отвёл генератор. Пилот — раздел
о финитно аппроксимируемых группах, `data/archive/grp/ф-а.jsonl`.

## Покрытие

Всякая известная задача обязана попасть в одну из корзин, и корзину
назначает прогон `python3 -m algen.archive <файл>`, а не автор карточки:

| корзина | что значит |
|---|---|
| словарь | определение или равносильная переформулировка |
| закрыто генератором | выводится из базы правил или опровергается понятным контрпримером из библиотеки |
| факт | генератор не закрыл, ответ известен; это и есть содержимое архива |
| короткий довод | контрпример держится на значении с пометкой «короткий довод»: несколько строк, но не учебный факт; в выдаче скрыто, показать — `--короткие` |
| открыто | ответ неизвестен |
| **красный флаг** | задача не записывается в словаре, или генератор ответил не так, как следует из её уровня |

Красный флаг — недоработка генератора, а не свойство задачи. Число флагов
служит мерилом покрытия наряду с эталоном.

Контрпример закрывает задачу, только если он понятный. Если он держится на
значении с пометкой «трудно» в библиотеке (само значение — теорема или
требует идеи: ф. а. группы Григорчука, неф. а. S₃ ≀ ℤ), задача остаётся
фактом, а контрпример записывается в обоснование.

## Карточка

```json
{"id": "ФА-21", "раздел": "grp", "тема": "ф. а.",
 "тип": "наследование", "конструкция": "расширение",
 "формулировка": "Если N ◁ G и G/N ф. а., то G ф. а.?",
 "условие": "∀ G : Grp; ∀ N : Sub(G) | normal(N), residually-finite(N), residually-finite(G/N)",
 "цель": "residually-finite(G)",
 "ответ": "ложно", "уровень": "нетривиальное",
 "обоснование": "S₃ ≀ ℤ: …", "ссылка": "K. W. Gruenberg, 1957",
 "вне_словаря": [], "статус": "не проверено"}
```

* `условие`, `цель` — машинная запись в нотации телескопа (docs/нотация.md).
  Если словаря не хватает, их нет, а `вне_словаря` называет, чего не хватает.
* `статус` — «не проверено», пока карточку не сверил человек или источник.

## Классификация для людей

Три оси, и каждая прямо читается из машинной записи.

1. **Тема** — главное свойство или объект: ф. а., нильпотентность,
   свободные группы. Машинно — свойство в цели (или главное в посылках).
2. **Тип вопроса** — форма схемы конструкций:
   * *словарь* — определения и критерии;
   * *связь свойств* — один объект, P ⇒ Q;
   * *наследование* — свойство переходит через конструкцию; конструкция
     указана отдельно: подгруппа, фактор, расширение, вверх по конечному
     индексу, прямое или свободное произведение, сплетение, объединение
     цепи, автоморфизмы;
   * *пример* — существует ли объект с данными свойствами, или свойства
     конкретного объекта;
   * *открытый вопрос*.
3. **Уровень** — насколько задача тривиальна:
   * *определение*;
   * *правило* — один шаг, учебный факт; входит в базу;
   * *следствие* — несколько шагов из правил;
   * *понятный контрпример*;
   * *нетривиальное* — нужна своя идея, минуты три размышления;
   * *теорема* — именной результат, статья;
   * *открыто*.

Первые четыре уровня генератор обязан закрыть сам, иначе карточка получает
красный флаг. Остальные три и составляют архив.

## Пилот: ф. а. группы

34 карточки. Прогон: словарь 1, закрыто генератором 19, факт 5, красных
флагов 9. Все флаги — нехватка словаря: проконечное пополнение, nA,
ограниченный период, полупрямое произведение с условием, сплетение,
прямой предел, Out, BS(m, n), гиперболические группы.

По итогам пилота добавлены:

* правило «ф. а. подгруппа конечного индекса ⇒ группа ф. а.» (ФА-23);
* разбор схем с несколькими группами (×, ∗, ∏, Aut): поиск контрпримеров
  перебирает библиотеку на любой схеме, а значения построенных термов,
  которых нет в библиотеке, выводит из правил;
* свойства «хопфова», «линейная», «полициклическая» с 18 правилами
  (Мальцев, Хирш, Бернсайд–Шур, Ауслендер–Суон и учебные) и значениями у
  всех групп библиотеки.

## Тождества в элементах

Карточка с полем `тождество` («[a b, c] = [a, c][b, c]») решается в
относительно свободной группе многообразия, которое задают посылки: без
посылок — свободная группа, `abelian(G)` — ступень 1,
`le(commutator(G), center(G))` — ступень 2. Подробнее в
docs/тождества.md. Так закрыта задача 5.13 задачника Дыбковой, а в
`data/archive/grp/тождества.jsonl` лежат 7 карточек с коммутаторными
тождествами, все закрыты верно.
