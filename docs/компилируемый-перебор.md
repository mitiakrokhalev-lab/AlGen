# Компилируемый перебор без изменения класса

7 ноября 2026. Ветка `codex/native-enumeration` поверх PR #12.
Математические данные, правила и native fingerprint не менялись.

В C++ перенесён числовой DFS: пересечения битовых столбцов, покрытие,
проверки req/конфликтов, все собственные подмножества, support и упаковка
результатов. Python сохраняет подготовку формы, SAT для констант, нулевые
посылки, дальнейшие фильтры, вердикты и сжатие. Сохраняется порядок depth/j/g,
`n_alive` до минимальности, `empty` и кратность строк при перепаковке.
Direct-mask по всем строкам отделена от P0 по fixed.

Отдельный `minimal` также компилируется. Это тот же общий фильтр по исходным
keys, а не необоснованный пропуск: работает с fixed, произвольными
неминимальными PackedConditions, повторяющимися посылками и порядком blocks.
Результат хранится в независимых массивах. Python не вставляет каждое из
17 млн условий обратно по одному — данные передаются целыми блоками.

Backend включён по умолчанию для подходящего PackedConditions, VEC,
goals=None, k=0..3 и ключей до64бит. Linux little-endian, g++ и Python.h
нужны для компиляции; остальные случаи выполняет прежний Python, без потери
условий. Это fallback реализации, не сужение математического класса.
Маски целей поддерживают больше64литералов. Кэш .so задаётся исходником,
ABI Python, компилятором и flags, публикуется атомарно; старые кэши
Library/таблиц не перестраиваются. Сборка обычно нужна один раз на среду.

Вызов через PyDLL удерживает GIL, а C++ регулярно вызывает PyErr_CheckSignals.
Обычный SchemeTimeout/KeyboardInterrupt прерывает ядро; частичный результат
не возвращается как успех. C++ исключения обрабатываются на границе ABI,
буферы освобождаются и при отмене. CSR для req/clash не добавляет
квадратичной матрицы. Все входные NumPy-массивы удерживаются до конца вызова.

Откат: `ALGEN_NATIVE_ENUM=0`, `ALGEN_NATIVE_MINIMAL=0`.
В профайлере один `--python-enum` отключает оба. Старые leaf-флаги сами по
себе не отключают C++. Фактический backend/hash пишется в stages.jsonl.

стоят суммарно1167,994с wall /1165,940866с CPU; прежний Ulm-reference
переиспользован, тесты отдельно. Были небольшие тесты на другом CPU.

Большой контроль — G-10-13-705-707-708-709. Ровно17447922условия,
3030679empty, n_alive514696725. Python и C++ сохранили весь результат,
затем весь minimal. Все четыре бинарника по198724912байт совпали через cmp,
SHA `e0b9d1ea7011f4bf14fe7c915428da3227788bbf407c786c6fb04e47665a2f1e`.
Независимый reviewer прочитал все коды/support/empty чанками, проверил
порядок, диапазоны и маркеры. Сравнение не ограничивается числом вопросов.

Большой контроль имеет scope `native enumeration only`: вердикты, raw-report
и базис этой схемы НЕ досчитаны. `complete=true` здесь относится только к
запрошенным стадиям. Не считать его новым полным успехом stress-01.
Память выросла: C++ временно держит выходные буферы до передачи Python.
В этих контролях лимит соблюдён; отсутствие OOM на всём классе не доказано.

Это одна последовательность C++/Python большого случая и reused-reference
Ulm, не рандомизированные повторные замеры. Ограничения/версии loader и
профайлера сохранены в manifests; числовой C++ source hash неизменен.
Коэффициенты стадий не перемножаются и не переносятся на весь класс.
